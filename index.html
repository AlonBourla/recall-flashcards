About scheduling

This starter version uses a simple interval-based spaced-repetition scheduler. Rate each answer from Again to Easy; the next review date is calculated automatically. It is Anki-inspired, not an implementation of Anki's FSRS algorithm, sync, add-ons or full desktop feature set.
